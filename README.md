# yokbi.github.io

Personal site of Uğur Buğra Özkaya, served by GitHub Pages at https://yokbi.github.io.

Plain HTML/CSS/JS with no build step. All content (experience, projects, skills, TR/EN text) lives in
`assets/js/data.js`; edit that file to update the site. Interface labels are in `assets/js/main.js` (`UI`).

Local preview: `python3 -m http.server` and open http://localhost:8000.
